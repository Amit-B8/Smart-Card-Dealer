# Smart Card Dealer

A senior design project focused on building an automated
card-dealing system integrated with an interactive
multiplayer game management application.

## Overview

The system combines embedded hardware, motorized card
distribution, and a web-based application for managing
card games.

## Planned Features

- Automated card dispensing
- Motorized dealer rotation
- Multiplayer game sessions
- Interactive player dashboards
- Turn tracking and game rule validation
- Automatic scoring
- Hardware fault detection and recovery

## Initial Game Modes

- Blackjack
- Crazy Eights
- Custom dealing mode

## Project Status

Early development and planning.
